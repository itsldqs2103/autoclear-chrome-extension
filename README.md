# AutoClear

AutoClear is a simple browser extension that automatically clears browsing data when the browser starts.

## Features

- Automatically clears browsing data on startup
- Lightweight and easy to use
- Simple popup interface

## Permissions

This extension requires the following permissions:

- `browsingData` – Clear browser data
- `storage` – Store extension settings

## Installation

1. Clone or download this repository.
2. Load the extension as an unpacked extension in your browser:
   - Open your browser's Extensions page.
   - Enable **Developer Mode**.
   - Click **Load unpacked**.
   - Select the project folder.
